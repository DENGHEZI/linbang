## ✨ 功能特性

### 🧑‍💼 客户端（用户端）
- **便捷下单**：帮我送、帮我买、自定义服务单
- **实时定位**：自动获取当前位置，支持手动输入
- **在线支付**：支持微信/支付宝、银行卡绑定
- **钱包管理**：余额充值、交易记录、账单明细
- **优惠券系统**：新用户体验券、满减券
- **评价系统**：对骑手进行星级评价和文字评价
- **AI 智能客服**：智能问答、订单状态查询
- **消息通知**：订单状态变更实时推送
- **QR 扫码**：扫码取货/送达确认

### 🛵 骑手端
- **抢单大厅**：实时查看可接订单
- **配送管理**：接单、取货、送达全流程
- **收入统计**：每日/每周/每月收入明细
- **星级评级**：基于用户评价的信用体系
- **快速切换**：客户端/骑手端一键切换
- **服务发布**：骑手可发布自定义服务单
- **定位导航**：一键导航至取货/送达地点

### 🛠️ 管理后台
- **订单管理**：订单列表、状态跟踪、异常处理
- **用户管理**：用户信息、实名认证、学校验证
- **骑手审核**：骑手入驻审核、资质管理
- **数据统计**：订单量、交易额、用户数统计
- **财务结算**：平台佣金、服务费、骑手分成
- **内容管理**：服务类别、优惠券配置

## 🏗️ 技术架构

```
┌─────────────────────────────────────────────────────────┐
│                      客户端/骑手端                        │
│                    (uni-app 小程序)                       │
├─────────────────────────────────────────────────────────┤

│  │  orderProxy  │  │  userProxy  │  │   aiChat        │ │
```

## 🚀 快速开始

### 环境要求

- HBuilderX 3.8+
- Node.js 16+
- 微信开发者工具（可选）
- uniCloud 账号（阿里云/腾讯云）

### 安装步骤

#### 1. 克隆项目

```bash
git clone https://github.com/你的用户名/linbang.git
cd linbang
```

#### 2. 客户端/骑手端

```bash
# 使用 HBuilderX 打开项目
# 文件 → 导入 → 从本地目录导入
# 选择 "邻寝帮（客户端）" 目录
```

#### 3. 管理后台

```bash
# 使用 HBuilderX 打开 "邻寝帮（终端）" 目录
```

#### 4. 配置 uniCloud

1. 登录 uniCloud 控制台
2. 创建服务空间（建议：阿里云）
3. 将 `spaceId` 填入两个项目的 `manifest.json`
4. 上传数据库 Schema 和云函数

#### 5. 运行项目

**客户端：**
- HBuilderX → 运行 → 运行到小程序模拟器 → 微信开发者工具

**管理后台：**
- HBuilderX → 运行 → 运行到浏览器 → Chrome

## 📖 使用说明

### 客户端使用流程

1. **注册登录**
   - 微信授权登录
   - 完善个人信息（学校、地址等）

2. **发布订单**
   - 选择"帮我送"或"帮我买"
   - 填写取货/送达地址
   - 设置服务费用

3. **支付订单**
   - 选择支付方式（钱包/微信/银行卡）
   - 确认支付

4. **查看订单**
   - 实时查看骑手位置
   - 确认送达并评价

### 骑手端使用流程

1. **骑手注册**
   - 提交实名认证
   - 上传资质证明
   - 等待审核

2. **接单配送**
   - 抢单大厅选择订单
   - 导航至取货点
   - 完成配送

3. **收入管理**
   - 查看每日收入
   - 申请提现至银行卡

### 管理后台使用

1. 访问管理后台地址
2. 使用管理员账号登录
3. 管理订单、用户、骑手
4. 查看数据统计报表
